# 手机连接电脑 DSH

仅在需要电脑端的模型、余额和工作状态时使用。离线动画和独立 AI 模式不依赖电脑。

## 推荐：同一可信局域网

1. 电脑启动 DSH，确认 `dsh-pet 0.3.8` 已启用，并确认 DSH 本机 Web 端口。
2. 在电脑终端运行（替换实际 IP 和 DSH 端口）：

```powershell
node scripts/dsh-phone-bridge.mjs --host 192.168.1.10 --upstream http://127.0.0.1:3000
```

3. 桥接器监听 `7341` 端口。令牌在本工程 `.local/bridge-token.txt`，只在本机查看并填入手机「DSH 连接令牌」，不要提交或发到聊天中。
4. 手机「DSH 服务根地址」填 `http://192.168.1.10:7341`，宠物 ID 默认为 `main`。
5. 要用电脑模型对话，选择「DSH · 使用电脑端服务」，保存并测试；要同步工作状态，打开「同步 DSH 气泡与工作状态」。

桥接器需要 Node.js 20+。默认只监听本机，显式指定本机局域网地址才对手机可见。不绑定公网地址，不转发到公网。HTTP 局域网连接适用于可信网络；远程访问应使用自己管理的安全通道。若防火墙拦截，需要在系统中仅允许你的私有网络；脚本不会自动改防火墙。

只放行 state、chat、whisper、balance 四类桌宠接口，必须带令牌；不转发插件管理、配置修改、停机或任意 DSH 路由。终端按 Ctrl+C 即停止桥接。脚本不负责启动 DSH 本身。

## USB 调试连接

可把只监听电脑本机的桥接端口映射到手机：

```powershell
node scripts/dsh-phone-bridge.mjs --upstream http://127.0.0.1:3000
adb reverse tcp:7341 tcp:7341
```

手机地址改填 `http://127.0.0.1:7341`，仍需连接令牌。USB 调试只用于此连接方式，不是日常离线桌宠的必要条件。

## 实际支持的同步

- DSH 气泡正文与清空。
- 内置 106 段动画的点播。
- thinking、working、result、waiting、success、error 六档工作状态与原版文案。
- 钱包、积分、额度窗口三种余额显示和档位动画。
- DSH 对话与碎碎念，记录仍由电脑端按其规则保存，手机另存当前收到的对话。

第一版不是完整 DSH 远程控制台；自定义素材、任意 URL 动画、第三方插件锁/菜单/回执和电脑位置控制没有向手机开放。QQ/OneBot 也不会自动互通。
