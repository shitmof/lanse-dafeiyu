# 蓝色大肥鱼 0.1.0 · Android

首个可安装的 Android 独立桌宠版本，支持 Android 9 及以上。原版角色来自 PC2005-cloud/dsh-pet 0.3.8，保留 MIT 许可。

## 下载与安装

下载本页 `lanse-dafeiyu-0.1.0.apk`（约 250 MiB）。私有仓库需要登录有访问权限的 GitHub 账号。

安装后打开应用，点「开始陪伴」，允许显示在其他应用上层和通知。若需要长时间运行，在手机电池设置中允许后台活动；部分品牌还需要允许自启动。长按宠物可进入动作、聊天和停止菜单。

## 本版包含

- 全部 106 段原版动作、27 张表情包，随 APK 离线提供。
- 跨普通应用的透明悬浮、拖动、甩动、随机走动、吃饭/睡觉日程、熄屏暂停。
- 1–3 只宠物，大小、透明度、固定位置、人设、碎碎念设置。
- 明确标注的离线固定回应；配置自己的 OpenAI 兼容服务后可使用 AI 对话。
- 可选 DeepSeek 余额、DSH 对话和工作状态同步；连接说明在仓库文档中。
- 本机聊天历史与导出、密钥加密保存、通知栏停止入口、可选重启恢复。

## 验证与边界

在 Android 15 / API 35 的独立 MuMu 模拟器完成测试，346 项设备检查通过，完整检查了 24,354 帧动画。Release 构建、Android lint（0 个错误）和 APK 签名验证通过。

真实手机尚未连接测试；实际 AI 账户和 DSH 服务需要在设置中配置。接口使用真实本机 HTTP 测试服务验证，不能视为已连接用户的账户。

系统权限、锁屏、支付等禁止悬浮窗的界面可能隐藏宠物，厂商后台管理也可能终止服务。本版没有完整复制 Electron 托盘、多显示器、第三方 DSH 插件管理及任意外部动画；详见 `docs/ACCEPTANCE.md`。
