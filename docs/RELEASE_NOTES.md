# 蓝色大肥鱼 0.1.0

首个可安装的 Android 独立桌宠版本，支持 Android 9 及以上。基于原作者 **PC2005-cloud** 的 [dsh-pet v0.3.8](https://github.com/PC2005-cloud/dsh-pet) 改版。**代码 MIT；原版动画、提示词、源视频等素材另有禁止商用及二创署名要求**，详见[第三方来源与许可](https://github.com/shitmof/lanse-dafeiyu/blob/main/THIRD_PARTY_NOTICES.md)。

2026-10-24补充：用户真机反馈左右拖动范围过窄、浮窗菜单过大、动作重复及选择动作跳回App。这些问题已整理为[下一候选版实施与验收方案](https://github.com/shitmof/lanse-dafeiyu/blob/main/docs/0.1.1/蓝色大肥鱼_现版优化方案与验收.md)，**0.1.0原APK未修改，不代表这些问题已修好**。原包、标签和哈希保留供回退；本次只补充文档与许可说明。

## 下载与安装

下载本页 `lanse-dafeiyu-0.1.0.apk`（约 250 MiB），并阅读同页附带的第三方许可说明。仓库现公开；0.1.0包内旧许可展示未包含本次完整补充说明，下一候选版将补齐。

安装后打开应用，点「开始陪伴」，允许显示在其他应用上层和通知。若需要长时间运行，在手机电池设置中允许后台活动；部分品牌还需要允许自启动。长按宠物可进入动作、聊天和停止菜单。

## 本版包含

- 全部 106 段原版动作、27 张表情包，随 APK 离线提供。
- 跨普通应用的透明悬浮、拖动、甩动、随机走动、吃饭/睡觉日程、熄屏暂停。
- 1–3 只宠物，大小、透明度、固定位置、人设、碎碎念设置。
- 明确标注的离线固定回应；配置自己的 OpenAI 兼容服务后可使用 AI 对话。
- 可选 DeepSeek 余额、DSH 对话和工作状态同步；连接说明在仓库文档中。
- 本机聊天历史与导出、密钥加密保存、通知栏停止入口、可选重启恢复。

在 Android 15 / API 35 的独立 MuMu 模拟器完成测试，346 项设备检查通过，完整检查了 24,354 帧动画。Release 构建、Android lint（0 个错误）和 APK 签名验证通过。
