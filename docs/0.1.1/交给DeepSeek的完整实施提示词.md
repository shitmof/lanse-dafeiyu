## 必须解决（P0）

### P0-1 人物能贴到屏幕左右边缘

现状根因：`PetService.Pet` 用完整 16:9 透明画布（宽度 = 设置里的宠物画布宽度，高 = 宽 × 360/640）建窗；`clamp/step/save` 全用整窗宽高；`PetView` 为 `FIT_CENTER`。代表动画 480×270 画布的全帧可见并集约 `[146,44,327,248]`，左右透明区约 30%，260dp 画布会留下约 80dp 空隙。

实现要求：

1. 为全部 106 段生成/核验动画级元数据：原始尺寸、全帧可见并集 `visualBounds`、角色主体范围 `bodyBounds`、脚底/主体锚点、是否允许镜像。透明阈值保留柔和边缘，alpha≥16 只作诊断参考，不能直接当无损裁剪标准；自动提取后人工复核尾巴、头饰、道具、文字和宽特效动作。
2. 优先采用紧凑的实际宠物窗口：按元数据平移绘制原帧，保持人物大小与比例，不把裁剪后的图重新拉伸回旧画布宽；切换动作保持脚底/主体锚点稳定，不随每帧包围盒抖动。
3. 边界、保存坐标、拖动、甩动、回弹、漫游统一以**主体锚点 + 可用显示区域**计算；人物可见外缘与左右安全边界目标间隔 **0–8dp**；不要求出屏，不做边缘隐藏功能。
4. 特效/文字超出主体时，优先用朝向和屏内位置处理；现有合成 WebP 不能假定特效可拆。人物贴边与完整宽特效冲突时，提供具体动作截图评审取舍，不能重绘、删减，也不能又用整张透明画布限制所有普通动作。
5. 朝向翻转时包围盒同步做 `[W-right, W-left]` 变换；文字类 `noMirror` 必须数据驱动，禁止镜像。
6. 使用一致的 `WindowMetrics/WindowInsets` 坐标模型，兼容 API 28；处理状态栏、刘海、手势/三键导航、旋转和多窗口，不得重复扣 Insets。

### P0-2 紧凑菜单，直接在当前宠物上换动作

现状根因：`PetService.menu()` 一次展开 8 行，宽 200dp、字号 16sp、内边距大；`挑一个动作` 执行 `open("motions")`。请改成真正的局部小浮层。

规格：

- 根菜单建议 5 项：**换个动作 / 动作分类 / 工作状态 / 自动播放 / 更多**。同屏最多显示 5 行，少量滚动。
- “动作分类”显示原版 **13 类**；点分类在同一面板列出该类动作，局部滚动；返回上一级，不打开 App。
- “换个动作”立即从当前可用池选一个不同的动作，在当前宠物播放一次，结束恢复原模式。
- “更多”保留：和我聊聊、吃一碗白饭、说句话、查余额、安静/碎碎念、回到小窝、停止陪伴。停止陪伴最多两次点击；通知栏仍可停止。
- 只改被点中的那只宠物；App 仍可浏览/搜索/点播，但调用同一目录与调度器，不能用 App 预览替代浮窗效果。
- 尺寸：宽约 144–168dp 且 ≤ 可用宽 44%；字号 12–14sp；行高 40–44dp；内边距 6–8dp；圆角 8–12dp；可见高度 ≤ `min(288dp, 可用高 34%)`。
- 默认根菜单面积目标 **≤ 整屏 12–15%（目标 12%）**，同手机同缩放 **≤ 图3 旧菜单面积 60%**；窗口与真实点击热区一起缩小，不能只缩字体、保留巨大背景或透明热区。
- 菜单靠近宠物，自动选择上/下、左/右侧并夹在可用区内；点外部/Esc 收起。
- 大字体/无障碍模式允许至少 48dp 触摸目标并局部滚动；不能靠强压字小来满足面积指标。
- 点击框不能隐形变大：宠物窗、气泡窗、菜单窗都是局部小窗；人物周围原透明空白应让下层应用可点，不能用全屏透明层截获触摸，也不能认为 View 返回 `false` 就一定跨 Window 透传，必须在另一应用上实测。

### P0-4 自然轮播、去重、完整覆盖

现状根因：`PetView.play()` 设定 `REPEAT_INFINITE`；`PetService` 每 30 秒重选一次，且另一个漫游计时器会把动画覆盖成奔跑；`AnimationCatalog.scheduled()` 整小时固定吃饭/睡觉，`random()` 又可能反复抽同一段。

实现要求：

- 把“播放”和“决定播什么”分开：`AnimationCatalog` 管目录/元数据；每宠物一个 `PlaybackController`（状态/队列/去重/历史）；`PetView` 只负责解码和**一次**播放，播放结束回调给控制器；浮窗菜单只发意图；位置控制独立。
- 默认由动画结束回调驱动下一段，不再全片无限循环 + 每 30 秒强行覆盖；注册/注销结束回调，处理解码代次、停止/熄屏/重建后的旧回调失效；加载失败记录并切下一候选，不能高速重试卡死。
- 预解码下一段/受控双缓冲，避免白闪；限制缓存内存，不能一次解码 106 段。
- 优先级：停止/熄屏 → 拖拽等直接触摸 → 手动点播/工作状态 → 已启用的远程事件 → 普通自动播放。手动点播结束恢复之前的自动模式，不被漫游计时器抢播。
- 自动普通池 **85 段** = 待机 1 + 转向 1 + 移动 3 + 五个日常分类 80（小动作/玩耍/吃什么/时节/文字）。采用类别加权 + 类别内洗牌袋 + 全局最近 6 段排除；候选充足时不连续重复；完整一轮覆盖启用池后再重建；权重可调但不得让某类永远饿死。
- 其余 21 段（拖拽 1、点击 5、余额 6、碎碎念 3、工作 6）按事件或手动触发，不伪装成真实事件；全 106 段始终可手动点播，另提供本地“全动作巡演”检查模式逐段播放并记录。
- 点击回应按原版 5 段轮换；饭点/夜间只提高相关类别权重或选一组，不整小时固定一段；固定位置只禁止位移，仍可换动作；移动动画与位移由同一次计划驱动。
- 文字类 `noMirror` 朝右时不得镜像；文字类被点播时按既有规则强制朝左或保持不镜像。

- 默认“播完自动换”；可选自定义间隔 **5–300 秒**，定义为**最短切换间隔，且当前片播完再换**：片长超过间隔不截断；片长短可停留末帧等间隔，或由用户显式选择期间循环。
- 可“暂停自动切换”；暂停时继续当前片或暂停画面要有清楚文案，不偷偷恢复 30 秒计时器。
- 设置落盘：自动模式、间隔、漫游、固定位置、本地工作状态是否持续、静音；重启恢复可预期。
- 熄屏暂停播放和自动切换；亮屏只恢复一次，不补发熄屏期间积压动作；停止/权限撤销后清理回调、解码引用、网络任务与窗口。

### P1-3 真实余额（零模型 token）

- 保留并完善 `PetApi.balance()` 的 DeepSeek 官方 `GET https://api.deepseek.com/user/balance`；解析 `balance_infos` 的真实币种、总额、赠送额、充值额、可用标识；多币种分别展示，不混加。

- 不支持的 API 服务明确提示“不支持”，**不得回退到 chat/completions**；余额动画只是装饰，接口没给使用百分比就不要伪造。

## 验收与证据

必须真实构建、安装、运行，不能只交计划或截图。至少覆盖：

1. **边界**：用户手机或同尺寸模拟器，普通桌面把人物拖到左/右极限，人物可见外缘距安全区 0–8dp；上/下尊重 Insets；旋转、不同大小、待机/吃饭/拖拽/宽特效/文字/镜像不跳位、不严重裁切。
2. **菜单**：同手机同缩放截图对照图3；新根菜单面积 ≤ 整屏 15%（目标 12%）、≤ 旧菜单 60%；真实窗口和热区同步缩小；普通字体和大字体都可用；停止 ≤ 2 次点击。
3. **直接换动作**：在另一普通应用上，点“换个动作/分类/具体动作/工作状态/自动设置”立即响应，下层 Activity 始终保持前台；只有“回到小窝/和我聊聊”才打开 App。
4. **完整目录**：13 类 106 段逐段可手动点播，记录 ID/类别/开始/结束/是否播完；不能拿“文件存在/能解码”代替“实际播完”。
5. **调度**：固定种子验证自动池一轮覆盖 85 段、无连续重复、最近 6 段排除；默认亮屏 15 分钟目标 ≥30 种动作（不足时提供轨迹与原因，不能只报随机抽样通过）；手动不受漫游抢播；饭点不整时段同片；固定位置仍换动作。
6. **设置**：5 秒/60 秒、片长短于/长于间隔、暂停、保存、重启、熄屏/亮屏不积压。
7. **工作状态**：未配置任何 API 时六档全可用、可退出恢复自动、文案不伪造真实任务。
8. **余额**：本地 HTTP fixture 覆盖成功/多币种/401/超时/节流/缓存；确认 0 次聊天请求；真实账户另测，缺凭据就标“未测”，不索取/输出密钥。
9. **资源与生命周期**：1→3→1 只宠物分别点播/拖动/停止；透明区下层可点；停止后零窗口/零残留菜单；启停 20 轮、权限撤销、服务重建无崩溃/泄漏。
