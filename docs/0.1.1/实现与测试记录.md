# 蓝色大肥鱼 0.1.1：实现与测试记录

日期：2026-10-24。基线：`v0.1.0`（提交 `5b7ce6d1978ae5dfa0e0c00276fd235d0fff5f87`）。实现分支：`deepseek/0.1.1-base`。
本轮已修改 App 代码并构建 **debug 测试 APK**；原 0.1.0 的 tag、Release 与 APK 均未覆盖。正式签名包因本机发行密钥缺失，尚未产出，详见“已知问题”。

## 1. 实现了什么

| 用户问题 | 实现 |
| --- | --- |
| 左右拖不动、人物离屏幕边还有空隙 | 每段动画读取 `visual` 可见范围（由 `scripts/prepare_assets.py` 对全帧 alpha 求并集生成）；窗口裁到可见范围，绘制保持原尺寸，拖动/回弹/漫游/保存统一按身体锚点计算，贴边时可见外缘只留约 2dp 透明 padding。 |
| 长按菜单约占 1/4 屏 | 重写为单面板紧凑浮层：宽 156dp，根菜单 5 项（换个动作 / 动作分类 / 工作状态 / 自动播放 / 更多），行高 42dp、字 13sp；分类和动作列表在同一面板逐级替换并局部滚动。 |
| “挑一个动作”跳回 App | 换动作、13 类分类、具体动作、工作状态、自动播放全部在悬浮面板内完成；只有“和我聊聊”“回到小窝”调用 Activity。 |
| 106 段只看到几段、重复 | `AnimationCatalog` 恢复 13 类 106 段；每只宠物独立 85 段洗牌袋 + 最近 6 段排除；`PetView` 改为**一次播完**并回调，`Pet` 用同一调度器接下一段；删除 30 秒强行重选和独立漫游抢播。 |
| 没有 DSH 任务也想有工作姿态 | 增加本地六档工作状态（思考/工作/整理/等待/成功/出错），菜单和 App 设置都可触发；持续状态会重播同一段本地动画，不调用模型。 |
| 不能自己定时换动作 | 增加“自动播放”开/暂停与 5–300 秒最短间隔；语义是当前片播完后再换，长片不截断；设置落盘。 |
| 余额真实且不浪费 token | `PetApi.balance()` 保留 DeepSeek 官方余额接口，多币种；新增更新时间。本地动作/工作/碎碎念默认台词均不发送模型请求。 |
| 点击框不能大 | 窗口本身即可见主体（加 2dp padding），不再用整张 16:9 透明画布接收触摸；菜单窗口也是实际面板大小。 |
| 许可与来源 | 新增 `app/src/main/assets/THIRD_PARTY_NOTICES.txt`；App「关于」入口可读；README/Release 已补来源与素材限制。 |

## 2. 代码改动

- `app/src/main/java/com/lanse/fish/PetView.java`：一次播放、结束回调、播放代次、可见范围 Matrix 裁切。
- `app/src/main/java/com/lanse/fish/AnimationCatalog.java`：13 类目录、85 段自动池、洗牌袋、5 段点击回应、本地工作姿态映射。
- `app/src/main/java/com/lanse/fish/PetService.java`：紧凑菜单、分类/动作/工作/自动页、可见边界拖动、单动画调度、本地工作状态、余额更新时间与节流。
- `app/src/main/java/com/lanse/fish/MainActivity.java`：设置页新增自动播放/间隔/本地工作状态六键；关于页补齐 0.1.1 与许可入口。
- `app/src/main/java/com/lanse/fish/PetApi.java`：余额结果显示更新时间。
- `app/build.gradle`：versionCode 2 / versionName 0.1.1。
- `app/src/main/assets/catalog.json`：13 类、106 条、每段 `visual` 归一化可见边界。
- `scripts/prepare_assets.py`：恢复 13 类映射；生成 `visual` 元数据（需要 Pillow + numpy）。
- `.github/workflows/android.yml`、`README.md`：构建依赖加 `numpy`。

## 4. 已知问题（必须带进验收）

1. **正式签名 APK 无法生成**：本机 `C:\Users\jyr09\AppData\Local\BlueFatFish\signing\release.jks` 缺失，`:app:validateSigningRelease` 失败。当前可测试包是 **debug 签名**，不能覆盖安装 0.1.0 正式包；用户需在测试机卸载旧包，或提供原发行密钥后再构建同签名候选。不得生成新密钥冒充升级。
2. **未连接真实 DeepSeek 账户、真实 DSH**：余额成功/失败/多币种、DSH 工作状态同步仍以本地 fixture 或代码路径为准，未在真实账户上验证。
3. **真机未测**：未在用户自己的手机、Android 9–14/16、窄屏或厂商系统上测试；横竖屏、刘海/手势导航、后台存活需用户实测。
4. **点击回应/工作态视觉逐项复验未做**：代码已接 5 段点击与 6 段工作动画，但未逐段截图核对每一段。
5. **菜单点外关闭、无障碍大字体**未单独实测。
6. **App 动作页预览**仍是一次播放（不再无限循环）；这是预览行为，不影响悬浮宠物调度。
7. **自动轮播间隔**在模拟器设置到约 10 秒验证；5 秒与 300 秒边界未逐项截图。
