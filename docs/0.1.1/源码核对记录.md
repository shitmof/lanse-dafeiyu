## REA实调用

工具：[morluto/rea](https://github.com/morluto/rea)，包`rea-agents@6.7.0`。使用项目内隔离安装，禁用安装脚本，不改变全局MCP配置；安装目录`research/v0.2-design/tools/`为前一调研阶段沿用的本机工具目录，不表示本轮继续开发AI陪伴。

```powershell
npm install --prefix research/v0.2-design/tools --ignore-scripts --no-audit --no-fund --save-exact rea-agents@6.7.0
& ./research/v0.2-design/tools/node_modules/.bin/rea.cmd analyze-javascript-application ./research/0.1.1-review/upstream/dsh-pet --source-path src/shared/menu.ts --source-path src/shared/pickers.ts --source-path src/shared/motion.ts --source-path src/shared/state.ts --source-path src/client/pet.ts --source-path runtime/electron-helper/sprite.js --source-path src/host/balance/providers/deepseek-official.ts --max-semantic-nodes 60000 --max-semantic-nodes-per-file 12000 --analysis-timeout-ms 60000 --format json --full-output > research/0.1.1-review/rea-upstream-analysis.json
```
