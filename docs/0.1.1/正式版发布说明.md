# 蓝色大肥鱼 0.1.1 正式版

本版接续 0.1.1 测试阶段，集中修复手机悬浮宠物的拖动、动作续播、页面切换和 API 兼容问题。点击 Q弹保留；不扩展新的 AI 陪伴、任务系统或人设卡功能。

下载：[0.1.1 正式发布页](https://github.com/shitmof/lanse-dafeiyu/releases/tag/v0.1.1)。包名 `com.lanse.fish`，`versionCode 8`，支持 Android 9 及以上。

## 本次完成

| 用户反馈 | 正式版行为 |
| --- | --- |
| 左右提前停住、起拖跳位 | 保留小悬浮窗，统一屏幕坐标与窗口边界；手势期间锁定当前动画、裁切矩阵、窗口尺寸及朝向，只更新位置。窗口更新合并到显示帧，避免每个触摸事件重复要求窗口重排。 |
| 拖动变形、点击换位置 | 跨过拖动阈值后立即恢复纵向比例 1.0；取消拖动开始/结束时强制换片和翻转。点击只做 Q弹与气泡回应，不换裁切窗口；响应动作仍可从动作分类中手动播放。 |
| 拖着不动就卡在最后一帧 | 拖动中循环同一个已加载动画，松手恢复单次播放和调度；新动作异步解码完成后暂存，等手势结束再同时提交画面与裁切。等待解码时不提前停住旧动画。 |
| 触摸后不再换动作 | 动画结束状态一直保留到下一段开始；拖动取消、菜单关闭、亮屏及工作状态保持分别恢复调度。 |
| 动作单调、已有动作无法直接选 | 106 段全部保留，按原有分类在悬浮菜单直接播放；日常自动池 85 段按洗牌轮换，近期动作避重，其余响应及工作动作按场景触发。换动作无需回主应用。 |
| 需要定时切换及工作状态 | 本地时段触发吃饭、小憩，保留六档工作状态及自动播放开关；这些行为不请求模型、不消耗 token。 |
| 菜单太大 | 长按菜单保留紧凑分层：换个动作、动作分类、工作状态、自动播放、更多；原有聊天、吃饭、余额、回小窝等入口在更多中。 |
| 点击 Q弹 | 保留按压 0.92、松手 1.05 → 1.0 的纵向反馈，独立于朝向镜像。 |
| 切页面闪退或错误动作回调 | 修复 Android 动画结束事件排队后清空回调造成的闪退；每段动画保留弱引用观察者，以当前播放状态过滤过期回调，取消过时的解码任务。 |
| 配好 API 仍不能聊 | 保留真实测试消息、失败卡片、草稿和手动重试；增加 `max_tokens` / `max_completion_tokens` / 服务默认三种长度参数，拒绝空模型及重复的完整端点。模型列表通过不代表聊天通过。 |
| 失败信息泄露请求内容 | HTTP 错误只显示状态及本地诊断摘要，不显示服务端原始错误正文；不把推理字段当聊天正文，不自动重试付费请求。 |
| 从测试包迁移 | 新增导入旧版导出的聊天 JSON；仅接收用户/助手消息，最多保留最近 200 条，导入前确认替换。密钥不随记录导出。 |

“玩游戏”等动作是随包动画，不依赖另装游戏，也不会为了播放动作调用模型。余额查询使用余额接口，不通过聊天模型推算；服务不支持时显示真实失败，不编造余额。

## 安装与数据迁移

- **0.1.0 正式版用户：直接覆盖安装。**沿用原发行证书，不需要卸载。
- **test.1–test.5 debug 用户：**旧应用「设置 → 导出聊天记录」，保存到公共文件夹；确认文件存在后卸载测试包，安装正式版，再在「设置 → 导入已导出的聊天记录」恢复。API 密钥和其他个人设置需重新填写。不同证书不能覆盖安装；卸载会清除应用内部数据。
- 允许悬浮窗和通知；如需长期运行，在手机系统中允许后台运行。系统安全页面、锁屏及厂商后台管理仍可限制悬浮窗。

API 配置应填写服务根地址（例如包含 `/v1` 的服务根路径），不要填写最终 `/chat/completions` 端点。明确发送一次真实测试消息后，再在聊天页发送。自动 AI 碎碎念默认关闭。

## 构建与验证范围

- JDK 17、Android SDK 35；正式签名构建及 `lintRelease` 通过。
- 主机回归：18 个动作控制器场景、13 个本机 HTTP/API 场景、11 个窗口验收器场景通过。提取真实控制器的夹具复现左边缘点击约 22dp 位移，修复后中心及两侧点击位移均为 0；拖动中比例为 1.0，窗口和动作不变。这些数值不是 iq15 真机测量。
- Android 15 专用模拟器 461 项检查通过：106 段动画真实解码、透明通道、自动池完整轮换、Keystore、本机 HTTP、单只/三只宠物生命周期及停止清理；动画重播、暂停、结束事件排队后销毁；跨过原动画约 10 秒时长的 12 秒持续播放；实际注入触摸检查拖动尺寸、松手位置及点击位置。
- 正式签名包：执行 0.1.0 → 0.1.1 覆盖安装；900×1600、360dpi（逻辑宽 400dp）手机竖屏布局下检查桌面、第二应用、拖动、长按菜单、聊天入口、熄屏恢复及停止；边缘检查使用实际窗口 frame，而非请求参数，10 次左右慢/快拖动通过。
- **未验证：**用户 iQOO/iq15 真机、厂商返回手势及主观触摸手感、真实 API 账户、三只宠物重叠时的完整边界组合。软键盘专项也未通过验证：MuMu 默认输入法不绘制普通手机键盘，且拒绝切换测试输入法；键盘可见但 inset 为 0 的结果不算通过。现有 `adjustResize` 与 IME Insets 处理保留。

本机 HTTP 夹具使用假密钥，验证真实请求与响应处理，但不能替代用户服务的账号、模型权限及协议兼容性。未把模拟器结果称为真机通过。
